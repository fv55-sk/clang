Single-Subscripted Arrays: Core Model

Contiguous memory, pointer degradation, and element initialization rules.

Study Phase: Concept Encoding + Active Retrieval

Feynman Prompt: Explain Array Names as Pointers

Why does passing an array name to a function implicitly pass it by reference? Write a 1-sentence plain-language explanation below:

1. Fundamentals & Declaration

An array is a fixed-size collection of items of the identical data type located contiguously in memory.

// Syntax: dataType arrayName[arraySize];
int num[10];      // 10 integers allocated contiguously
char name[30];    // 30 characters allocated

2. Initialization Variants

  • Full initialization: int num[5] = {1, 2, 3, 4, 5};
  • Zero initialization: int num[10] = {0}; sets index 0 to 0 and forces the compiler to pad all remaining indexes with zero.
  • Partial initialization: int num[10] = {1, 2, 3}; sets indices 0, 1, and 2 to 1, 2, and 3; indices 3 through 9 automatically initialize to 0.
  • Unsized initialization: int num[] = {1, 2, 3, 4, 5}; sets size dynamically based strictly on the initializer count (size = 5).

3. Memory Layout

The array name itself contains the memory address of the first item (&num[0]). Hence, the array name is a constant pointer pointing directly to index 0.

[0]1
[1]2
[2]3
[3]0
[4]0
Active Recall: What happens if you initialize `int a[5] = {2};`?

Index 0 is set to 2, and indexes 1, 2, 3, and 4 are automatically set to 0.

1D Arrays: Insertion and Deletion Algorithms

Pointer-driven index manipulations and shift logic.

1. Insertion at Front (`addFront`)

To insert an element at index 0, every preexisting element must be shifted right by one slot starting from the end to avoid overwriting elements.

// Algorithm Version 1 (downward from count)
void addFrontV1(int num[], int *count, int item) {
    for (int i = *count; i > 0; i--) {
        num[i] = num[i - 1];
    }
    num[0] = item;
    (*count)++;
}

// Algorithm Version 2 (downward from count - 1)
void addFrontV2(int num[], int *count, int item) {
    for (int i = *count - 1; i >= 0; i--) {
        num[i + 1] = num[i];
    }
    num[0] = item;
    (*count)++;
}

2. Generalized Insertion (`addAt`)

Generic insertion allows inserting at an arbitrary pos within current array bounds:

void addAt(int num[], int *count, int item, int pos) {
    for (int i = *count; i > pos; i--) {
        num[i] = num[i - 1];
    }
    num[pos] = item;
    (*count)++;
}

3. Deletion Algorithms

  • Delete End: Simply decrement count: (*count)--;
  • Delete Front: Shift left starting adjacent to the deleted index:
// Delete Front (Version 1: i starts at 0, ends at count - 2)
void deleteFrontV1(int num[], int *count) {
    for (int i = 0; i < *count - 1; i++) {
        num[i] = num[i + 1];
    }
    (*count)--;
}
Active Recall: Why must *count be passed as an int* pointer?

Because C passes parameters by value; modifying the counter tracking the valid elements in caller memory requires pass-by-reference via a pointer.

Two-Dimensional Arrays: Rows & Columns

Row-major ordering, table mapping, and grouped initializations.

1. Declaration & Subscript Model

// Syntax: dataType arrayName[rowSize][colSize];
int table[3][4]; // 3 rows, 4 columns (12 total elements)

2. Initializer Formats

Initialization SyntaxResulting Layout Behavior
int t[3][4] = {0}; All 12 positions are zeroed out.
int t[3][4] = {1, 2, 3, 4, 5, 6}; Fills row 0: {1,2,3,4}, row 1: {5,6,0,0}, row 2: {0,0,0,0}. Linear filling with remainder zeroed.
int t[3][4] = {{1,2}, {5,6,7}}; Grouped explicitly: Row 0 gets {1,2,0,0}, Row 1 gets {5,6,7,0}, Row 2 gets {0,0,0,0}.
Active Recall: In `int a[2][3] = {{1}, {4, 5}};`, what is `a[0][2]` and `a[1][0]`?

a[0][2] == 0 (unfilled in row 0) and a[1][0] == 4 (first element of row 1).

Passing 2D Arrays to Functions

Column boundary requirements and modular decomposition.

1. The Column Bound Requirement

When passing multi-dimensional arrays to functions, the column size must be specified so the compiler can compute memory jump offsets (row stride) correctly.

#define ROW 3
#define COL 4

// Function prototypes - Column size mandatory:
void input(int table[][COL]);
void display(int table[][COL]);
int getTotal(int table[][COL]);

2. Standard Nested Iteration

void display(int table[][COL]) {
    for (int row = 0; row < ROW; row++) {
        for (int col = 0; col < COL; col++) {
            printf("%3d ", table[row][col]);
        }
        printf("\n");
    }
}

Character Arrays & Strings

Null-terminator sentinels and string array initialization.

1. The Null Character Sentinel

A string in C is a one-dimensional array of characters terminated by the null character '\0'. The null sentinel informs functions and loops where the sequence ends.

2. The Three Initialization Methods

  1. String literal: char s[10] = "hello"; (compiler automatically appends '\0').
  2. Individual characters: char s[10] = {'h','e','l','l','o','\0'}; (requires explicit '\0').
  3. Input Stream: gets(str); (appends '\0' automatically upon pressing Enter).
[0]'h'
[1]'e'
[2]'l'
[3]'l'
[4]'o'
[5]\0
[6]?
Active Recall: Is '\0' included in string length counts?

No. The null character is purely a terminator/sentinel marker; it indicates the boundary and is not counted as part of the string's length.

Passing Strings to Functions

Why strings do not require passing size parameters.

1. Termination via Sentinel Loop

Unlike numerical arrays which require passing array size or count, strings carry their own boundary marker: '\0'.

// Count occurrences of letter 'A' or 'a'
int countAs(char str1[]) {
    int count = 0;
    for (int i = 0; str1[i] != '\0'; i++) {
        if (str1[i] == 'a' || str1[i] == 'A') {
            count++;
        }
    }
    return count;
}

Structures: Definitions, Syntax & Typedef

Custom composite data types, data members, and aliases.

1. Definition vs Variable Declaration

// Definition
struct Student {
    int idnumber;
    char name[30];
    int age;
    float tuitionfee;
};

// Variable declaration
struct Student s;
// Initializer list
struct Student s1 = {101, "Jose Rizal", 18, 24500.25};

2. Typedef Patterns

// Pattern 1: Separate typedef
typedef struct Student Stude;

// Pattern 2: Tag + Typedef combined
typedef struct Student {
    int idnumber;
} Stude;

// Pattern 3: Anonymous struct + Typedef
typedef struct {
    int idnumber;
    char name[30];
} Stude;

Note: typedef does not invent a new data type; it generates a type alias to avoid prepending the keyword struct.

Advanced Structures: Pointers, Arrays & Nesting

Dot operator vs Arrow operator, nested struct resolution, and struct arrays.

1. Dot Operator (.) vs Arrow Operator (->)

  • Dot operator (.): Used directly on struct variables: s.age = 20;
  • Arrow operator (->): Used through a pointer: sptr->age = 20; (syntactic sugar for (*sptr).age = 20;)

2. Passing Structures to Functions

  • Pass-by-value: void display(Stude s); copies the entire structure.
  • Pass-by-reference: void input(Stude *s); passes the address (using &s in caller) to allow modifying members via s->idnumber.

3. Nested Structs & Validation Rule

struct Name { char fname[30], lname[30]; };
struct Bio { struct Name nm; int idno; };
struct Bio x;

// Valid:   x.nm.fname
// Invalid: x.Name.fname (must reference variable nm, not type Name)

Dynamic Data Structures: Stack vs Heap

Static allocation vs Dynamic allocation, malloc, calloc, and pointer targets.

1. Architectural Differences

FeatureStack MemoryHeap Memory
Allocation TimingCompile time / automatic function callRun time (on demand)
Management OrderLIFO (Last-In-First-Out)Unordered / arbitrary block allocation
Access SpeedExtremely fast (single stack pointer)Slightly slower
Size LimitationsFixed / restricted stack limitsBounded only by virtual memory
C FunctionsOrdinary local variablesmalloc(), calloc(), free()

2. `malloc()` vs `calloc()`

// malloc (memory allocation) - Leaves memory UNINITIALIZED (garbage data)
int *ptr = (int*) malloc(10 * sizeof(int));

// calloc (contiguous allocation) - Clears and INITIALIZES all bits to ZERO
int *ptr2 = (int*) calloc(10, sizeof(int));
Active Recall: Why do dynamic memory allocations in the heap require a static pointer?

Memory blocks allocated on the heap have no variable names; the only mechanism to access or operate on them is by storing their base address in a pointer variable (stored on the stack).

Dynamic Arrays & Memory Deallocation

Subscript syntax parity with static arrays and memory release.

1. Complete Dynamic Array Lifecycle

#include <stdio.h>
#include <stdlib.h>

int main() {
    int size = 5;
    // 1. Allocate heap memory
    int *ptr = (int*) malloc(sizeof(int) * size);
    if (ptr == NULL) return 1; // Error check

    // 2. Access identically using array index subscript notation
    for (int i = 0; i < size; i++) {
        ptr[i] = (i + 1) * 10;
    }

    // 3. Deallocate memory
    free(ptr);
    ptr = NULL; // Prevent dangling pointer
    return 0;
}
